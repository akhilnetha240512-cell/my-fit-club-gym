PUBLISHING ON GITHUB PAGES (ANDROID)
------------------------------------
1. Download and extract this ZIP on your Android device.
2. Open your GitHub repository:
   https://github.com/akhilnetha240512-cell/my-fit-club-gym
3. Open index.html, choose Edit, replace its contents with this package's index.html.
4. Commit the change to the main branch.
5. Repeat for style.css and script.js.
6. Wait for GitHub Pages to deploy, then check:
   https://akhilnetha240512-cell.github.io/my-fit-club-gym/
