# Power Gym website demo

A responsive single-page gym website made with HTML, CSS and JavaScript.

## Preview on your phone
1. Download and extract `power-gym-website.zip`.
2. Open `index.html` in a browser, or upload the three files to a static host such as GitHub Pages.
3. Internet is needed for the remote Unsplash photos and Google Fonts.

## Before showing it as the real gym website
- Replace “Power Gym” with the real business name.
- Replace sample photos with photos the owner approves.
- Confirm actual services, prices, phone number, WhatsApp number and address.
- Update the Google Maps link in `index.html`.
- In `script.js`, replace `91XXXXXXXXXX` with the gym's WhatsApp number including country code, without `+` or spaces.
- Test the enquiry form and all links on mobile.

Prices and business details are placeholders. The enquiry form opens WhatsApp; it does not save submissions to a database.
